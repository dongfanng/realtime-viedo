# Lucy → OBS → 微信 画面适配计划

## 背景与问题

使用 OBS 采集浏览器中 Lucy 返回的视频，再作为微信视频通话的虚拟摄像头输入时，因三方分辨率/比例不一致，微信聊天界面常出现**画面显示不全**或观感模糊。

微信官方未向普通用户提供视频通话分辨率调节入口；通话清晰度由微信自适应编码决定，主要受网络、采集源、通话类型与设备状态等影响，**不能指望在微信里调高分辨率来解决构图问题**。

## 目标

1. 微信视频预览中主体构图完整、比例正确（优先解决「显示不全」）。
2. 在微信画质上限内，尽量保证输入清晰、稳定。
3. 全链路使用同一宽高比，避免 OBS / Lucy / 微信各自裁切或留黑边。

## 核心原则

| 原则 | 说明 |
|------|------|
| 先定比例，再定像素 | 不必抠微信窗口精确像素；先对齐视频预览区宽高比 |
| 画布与浏览器同源比例 | OBS 画布与浏览器源宽高比必须一致，建议像素也一致 |
| 微信调不了分辨率 | 优化喂入端与网络，而非寻找微信内分辨率开关 |
| 比例正确优于堆高分辨率 | 720×1280（9:16）通常足够；盲目 1080p/4K 加重本机负担，对端未必更清 |

## 分辨率参考（页面 / OBS）

与 `src/main.js` 中 `ASPECTS` 保持一致：

| 比例 | 推荐像素（宽×高） |
|------|-------------------|
| 9:16（微信） | **360×640**（默认） |
| 9:16 高清 | 720×1280 |
| 3:4  | 720×960 |
| 4:5  | 720×900 |
| 1:1  | 720×720 |
| 4:3  | 960×720 |
| 16:9 | 1280×720 |

页面中央有固定像素「舞台」；OBS 画布设为相同像素。用 macOS 屏幕采集时，请裁切到中间舞台，或把浏览器窗口缩到刚好包住舞台。

## 标准流程清单

1. **页面**：选 `9:16 · 360×640 微信`，勾选「按比例裁剪」，连接
2. **纯净模式**：按 `H`（**不要** F11 全屏，否则比例变成显示器 16:9）。舞台保持 360×640。
3. **OBS（推荐）**：用 `npm run capture` 打开无标签栏的 Chrome 应用窗（先 `npm run dev`），或普通 Chrome 亦可 → macOS 屏幕采集选该窗口 → 画布 **360×640**。若仍含标题栏：选中源，按住 **Option** 拖边缘裁到舞台（非纯净时有蓝框对照）。
4. **OBS（备选：浏览器源）**：浏览器源打开本页并在源内点连接。Permission denied 时：OBS 菜单 → **Review App Permissions** 打开摄像头/麦克风；系统设置 → 隐私与安全性同步授权；关掉 Chrome 对本页的连接。
5. **若画面卡住**：浏览器源可关掉 Browser Source Hardware Acceleration；或改回「macOS 屏幕采集」抓 Chrome。
6. **虚拟摄像头**：启动 OBS Virtual Camera。
7. **微信**：设置 → 通用 → 视频 → 摄像头 → 选 OBS Virtual Camera（改分辨率后建议重启微信更稳）。
8. **微调**：显示不全 → 查比例是否一致；人物被裁 → 调页面「裁剪缩放」(`zoom`)；黑边过多可反向调节。

> 名称对照：`已废弃` 分组里的「显示器采集 / 窗口采集」= 旧 API，可忽略。要用的是源列表**上面**单独一项「macOS 屏幕采集」。

## 问题分层与对策

### A. 构图 / 显示不全（比例问题）

| 环节 | 对策 |
|------|------|
| 页面 | `#aspect` 选 `9:16 · 360×640`；勾选「按比例裁剪」；改后需重连 |
| 显示 | 中央固定舞台；纯净模式按比例铺满窗口；输出用 cover 铺满舞台 |
| OBS | 画布设为 **360×640**；屏幕采集后若仍含黑边，裁切到舞台或把浏览器缩成竖屏窗口 |
| 裁剪 | 调节 `zoom`（0=完整+黑边，100=裁满） |

### B. 清晰度 / 模糊（微信上限）

| 因素 | 对策 |
|------|------|
| 网络 | 双方尽量稳定 Wi‑Fi；弱网会动态降分辨率与码率 |
| 通话类型 | 优先 1v1；群视频官方规格通常更低 |
| 环境 | 光线充足、避免过热、必要时关美颜 |
| 输入 | 比例正确、主体居中、边缘留余量；不必过度推高 OBS 分辨率 |

若清晰度仍不可接受：可换腾讯会议/Zoom 等可选手动画质的通道，或用 OBS 本地录制 Lucy 输出（非微信通话场景）。

## 可选后续改造（代码）

- [ ] 纯净模式下 `#output` 使用 `object-fit: cover`，减少 OBS 视口与视频比例不一致时的黑边。
- [ ] UI 提示补全 **4:5 → 720×900**（与 `ASPECTS` 对齐）。
- [ ] 切换比例后自动提示或自动重连，避免 canvas 尺寸陈旧。
- [ ] 提供「一键复制当前推荐 OBS 画布尺寸」到剪贴板，降低配置出错。

## 验收标准

- [ ] 微信视频预览中人物/主体完整可见，无明显左右或上下被切。
- [ ] OBS 预览与微信预览构图基本一致（允许微信侧轻微再裁）。
- [ ] 稳定网络下通话可用，无因画布比例错误导致的拉伸变形。
